Privacy Policy

Last updated: October 30, 2026

This policy explains how YT Auto ("the app") handles information. The app is a private tool used only by the owner of the Star Money Stories YouTube channel to upload that owner's own videos.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app accesses

  • With the account owner's permission (Google sign-in), the app gets an access token that lets it upload videos, set video thumbnails and add captions on the owner's own YouTube channel.
  • The app does not read, collect or store any other Google account data, contacts, emails, viewing history or information about other YouTube users.

How the data is used and stored

  • The access token is stored only in a file on the owner's own computer and is used only to upload the owner's videos.
  • No data is sent to any server operated by the app's developer. There is no app server and no database.
  • No data is sold, shared, or used for advertising.

Revoking access and deleting data

Access can be revoked at any time from Google Account permissions. Deleting the token file on the owner's computer removes all stored data.

Contact

Questions about this policy can be sent through the Star Money Stories YouTube channel.
